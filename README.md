# 展示ブース装飾提出ツール

展示会ごとのブース寸法を切り替え、机・什器・コンセントなどの配置図を作り、PDFとして提出するための簡易ツールです。

## 使い方

1. `start_tool.bat` をダブルクリックします。うまく開かない場合は `index.html` をブラウザで開きます。
2. 展示会プリセットを選び、小間番号・会社名・担当者を入力します。
3. 左の「配置するもの」から備品を追加します。
4. 図面上の備品をドラッグして配置します。
5. 必要に応じて選択中の備品サイズや名称を変更します。
6. 「PDF出力」を押し、印刷画面で「PDFに保存」を選びます。

## 入っているプリセット

- WOF 東京: 3000 x 3000mm、壁高 2400mm
- IMF 大阪秋: 3000 x 3000mm、壁高 2400mm
- EGF 大阪春: 3000 x 3000mm、壁高 2400mm
- JEX 東京 2小間: 8000 x 2000mm、壁高 2100mm、付属テーブル W1500 x D600 2台
- 横長 2小間: 6000 x 3000mm、壁高 2400mm
- 奥行き広め: 3000 x 4500mm、壁高 2400mm
- 自由入力

## エージェント確認

画面左下に、次の確認欄を入れています。

- 寸法エージェント: ブース幅・奥行・壁高を確認
- 配置エージェント: 備品の重なりを確認
- 電源エージェント: コンセント配置の有無を確認
- 提出エージェント: 展示会名・小間番号・担当者の入力漏れを確認

## 保存と読込

「保存」で作業内容をJSONとして保存できます。「読込」で保存したJSONを戻せます。ブラウザ内にも自動保存されます。
