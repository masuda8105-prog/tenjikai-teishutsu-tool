# 展示ブース装飾提出ツール

展示会ごとのブース寸法を切り替え、机・什器・コンセントなどの配置図を作り、PDFとして提出するための簡易ツールです。

## 使い方

1. `start_tool.bat` をダブルクリックします。うまく開かない場合は `index.html` をブラウザで開きます。
2. 展示会プリセットを選び、小間番号・会社名・担当者を入力します。
3. 左の「配置するもの」から備品を追加します。電気機器を使う場合は、回路容量・コンセント・給電元・消費電力・余長を登録します。
4. ガチャコップA0002または専用台A0007を選ぶと「机上・専用台への配置」が表示されます。実寸適合する机を選び「中央へ正確に載せる」を押します。A0002は机へ直接、またはA0007へ載せられます。
5. 図面上の備品をドラッグして配置します。机上物は支持する机・専用台へ追従します。備品一覧の行からも配置物を選択できます。
6. 商品・POP・メイン商品を評価する場合は、対象什器を選び、評価区分、実測した注視高さ、表示面の正面を登録します。人物は「来場者視点」または「スタッフ起点」に設定できます。
7. 営業状態を確認する場合は「営業物品」を追加し、在庫・箱・バッグ・紙袋・ゴミ箱・販促物等の区分、実測W/D/H、表示状態を登録します。混雑人物は人物役割を「混雑負荷」にします。
8. 接客・スタッフ・在庫の床面積を検査する場合は「接客スペース」を追加し、用途区分、W/D、必要面積㎡、表示状態を登録します。在庫区分では総商品数、箱入数、補充回数、実測箱W/D/H、最大積上高も登録します。
9. 「設計／営業中／混雑時」を切り替え、衝突・視認・動線・床面積の差を確認します。
10. 必要に応じて選択中の備品サイズや名称を変更します。
11. 「PDF出力」を押し、印刷画面で「PDFに保存」を選びます。

## エージェント確認

画面左下に、次の確認欄を入れています。

- 寸法エージェント: ブース幅・奥行・壁高を確認
- 配置エージェント: 備品の重なりを確認
- 机上配置エージェント: 卓上商品の支持台指定、天板内収容、Z位置、メーカー指定組合せを確認
- 視認性エージェント: 登録視点から対象正面への視線と什器の高さによる遮蔽を確認
- 到達動線エージェント: 通路入口または登録人物から対象正面まで、必要幅を保つ連続経路を確認
- 床面積・用途領域エージェント: 通路側から到達できないデッドスペース候補、用途領域と什器の重複、必要面積不足、スタッフ起点の入口到達性を確認
- 在庫容量エージェント: 箱寸法・箱入数・補充回数・最大積上高から最大同時箱数と収容可能箱数を比較
- 高さ制限エージェント: 配置物上端と会場の装飾高上限を比較
- 電源エージェント: 未接続、消費電力・容量未登録、回路/電源タップ容量超過、什器を横断する配線を確認
- 提出エージェント: 展示会名・小間番号・担当者の入力漏れを確認

## 保存と読込

「保存」でv9のバージョン付きJSONを保存できます。「読込」は新形式と旧形式の両方に対応します。ブラウザ内にも自動保存され、X/Y/Z、W/D/H、回転角度、グリッド設定、机上の親子関係・相対位置・支持高、回路、給電元、配線方式、余長、人物役割、視認対象設定、動線必要幅、営業状態、営業物品区分、用途領域区分、必要面積、表示状態、実測確認状態、在庫箱・補充・積上げ条件を保持します。

## 精密設計・3D確認

- 10 / 50 / 100mmグリッドとスナップ切替
- X / Y / Z座標、90度回転、壁4方向の距離、最短什器間距離
- 2Dと3Dで同じ配置データを使用
- 正面・左右・俯瞰・来場者目線、視点高さ1000〜2200mm
- 範囲外、立体衝突、入口帯の連続開口幅、人物周囲の導線目安を検査
- 複製、Undo / Redo（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+D）
- PDF出力時に平面図と、什器・電源・設営配置順のサマリーを生成
- 電源回路、コンセント、電源タップ、照明・接続機器をIDで接続し、平面直交距離＋取付高低差＋登録余長からケーブル長を算出
- 配線を2Dと3Dへ同時表示し、提出サマリーへ回路別負荷と経路長を反映
- 商品・POP・メイン商品へ実測注視高さと表示面の正面を登録し、来場者視点からの正面条件と3D視線高さを使って遮蔽を検査
- 来場者未登録時は通路側3点を明示的な仮視点とし、人物登録時は実人物視点へ切替
- 50 / 100 / 200mm刻みの格子探索で、登録した必要幅を確保できる来場者・スタッフ経路を2D/3Dへ表示
- 視認性・到達性を提出サマリーと寸法仕様JSONへ反映
- 設計／営業中／混雑時の状態切替。状態別物品と混雑人物を一つの共通配置データに保持
- 無効状態の項目は2Dで薄く表示して編集可能なまま保持し、状態別衝突・視認・動線、3D、PDFから除外
- 在庫・予備品、梱包材、バッグ・紙袋、ゴミ箱、販促物・ガチャ用品、PC、ケーブル養生領域を状態別占有領域として登録
- 営業物品の実測確認漏れ、在庫スペース未登録、混雑人物未登録、PC電源設計不足を「問題箇所→理由→改善案」で警告
- 接客スペース、スタッフ専用領域、在庫予約領域を、什器とは別の非物理的な床面計画データとして登録
- 90度矩形の全X/Y境界で平面を分割し、障害物、通路側から到達可能な床、デッドスペース候補をmm²で重複なく集計
- 用途領域の什器重複、領域同士の二重計上、必要面積不足、スタッフ起点自体の入口到達不能を検査
- 2Dへ用途領域とデッドスペース候補の網掛け、3Dへ用途領域の薄い床オーバーレイ、提出表と寸法仕様JSONへ面積根拠を反映
- 在庫予約領域へ総商品数、箱入数、補充回数、箱W/D/H、最大積上高、確認状態を登録し、箱の平面90度回転2方向と整数積上段を比較
- 必要ピーク箱数、1段箱数、積上段数、容量箱数、不足箱数を2D、3D、提出表、寸法仕様JSONへ共通反映
- スペース渡しプリセットは未支給の壁を2D/3Dへ生成せず、会場装飾高上限だけを独立管理
- あミューズA0002（W240×D370×H440）、A0007（W250×D315×H100）、E1237（W275×D275×H460）を公式寸法ロック付き実在商品マスターとして登録
- A0002/A0007を実寸適合する机へ載せ、机移動へ追従。A0002＋A0007は公式の組合せ全高約530mmを優先し、A0002の支持高をZ90mmとして管理

回路容量・電源タップ定格・接続機器の消費電力は推測しません。商品/POPの注視高さと正面も推測せず、未登録は判定不能として警告します。空欄は会場、施工会社、実測図面の確定値で補ってください。X→Y/Y→Xは1曲がりの計画経路であり、現場の立上げ・養生・迂回条件は余長と施工指示で確定してください。動線必要幅と格子探索は設計確認用であり、避難・消防・会場規定の正式判定を置き換えません。

営業物品の初期W300×D300×H300mmは形状を推測した什器ではなく、入力開始用の仮占有領域です。実測W/D/Hへ変更して「寸法を実測・確認済み」を有効にするまでは警告されます。PC・端末の占有領域だけでは消費電力を計算しないため、電源が必要な場合は接続機器としても回路へ登録してください。

用途領域のW×Dは計画床面であり、物理的な什器ではありません。必要面積はツールが推測せず、想定人数・運用・社内基準・会場規定に基づく値を登録してください。面積集計は現在の90度矩形に対してmm²単位で正確です。斜め形状、扉、段差、消防・避難条件は別途図面と会場規定で確認してください。

在庫容量は、総箱数を（補充回数+1）で均等分割した最大同時箱数を計画値にします。補充時期や数量が均等でない場合は、総商品数へ実際の最大同時保管数を入力してください。箱重量、床荷重、箱・什器の耐荷重、消防、避難、荷崩れ防止はまだ自動判定しません。

## 什器マスターの精度区分

boldaは提供印刷フォーマット名から外形W/D/Hを照合し、マスター寸法を編集ロックしています。段差・棚板・板厚・材質・組立方法は、メーカーCADや組立図が未提供のため暫定です。画面内でも確認済み外形と暫定3Dを区別して表示します。

あミューズA0002、A0007、E1237は公式商品ページの組立後W/D/Hを編集ロックしています。3Dはその正確な外形内に収めた参照簡略形状で、製造CADではありません。A0002＋A0007だけはメーカー指定組合せとして奥行方向27.5mmの張り出しを許可し、それ以外の机上配置は天板からの張り出しを許可しません。
